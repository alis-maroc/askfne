FNE Chatbot & Hub - Guide de Déploiement & Restauration

Procédure d'urgence pour réinstaller l'ensemble du système sur un nouveau serveur VPS/Dédié

DISASTER RECOVERY
Protection Garantie : Grâce à la structure Docker et aux scripts de sauvegarde du Dashboard, la réinstallation complète d'un serveur vierge prend moins de 10 minutes.

1. Prérequis du Nouveau Serveur (OS & Docker)

Sur un serveur vierge (Ubuntu 22.04 / 24.04 LTS ou Debian 12) :

# 1. Mise à jour de base
apt update && apt upgrade -y
apt install -y git curl wget unzip build-essential

# 2. Installation de Docker & Docker Compose
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker

# 3. Vérification
docker --version
docker compose version

2. Récupération du Code Source & Structure

Clonez le dépôt du projet sur le nouveau serveur :

# Cloner dans le répertoire de travail
git clone https://github.com/Hesper-Labs/owly.git /root/owly
cd /root/owly

# Créer les dossiers de stockage persistants
mkdir -p backups public .wwebjs_auth

3. Fichier des Variables d'Environnement (.env)

Créez le fichier /root/owly/.env contenant vos clés secrètes :

# Base de données PostgreSQL interne
DATABASE_URL="postgresql://postgres:d5872d7f116195dfe94a09208cf9546cc41de96e7665e60a0c62fb6a492f6631@db:5432/owly?schema=public"

# Clés IA (LLM)
OPENAI_API_KEY="votre_cle_openai"
GEMINI_API_KEY="votre_cle_gemini"

# URLs & Sécurité
NEXT_PUBLIC_APP_URL="https://ns516856.ip-158-69-24.net"
APP_BASE_URL="https://ns516856.ip-158-69-24.net"
JWT_SECRET="owly_fne_secure_jwt_secret_key_2026"
CORS_ORIGIN="*"

# Numéro et Jeton de partage WhatsApp
WHATSAPP_SHARE_TOKEN="votre_token_partage"

4. Configuration du Serveur Web Sécurisé (Caddyfile)

Caddy gère automatiquement les certificats SSL HTTPS Let's Encrypt :

# Fichier: /root/owly/Caddyfile
ns516856.ip-158-69-24.net {
    reverse_proxy app:3000
}

5. Dépendances Intégrées dans Docker (Chromium, PDF, Polices Kacst)

Note Importante : Le Dockerfile du projet intègre déjà automatiquement toutes les dépendances système requises :
  • chromium : pour le rendu des posters, reçus et impressions automatiques.
  • poppler-utils : pour le traitement et l'analyse des PDF officiels.
  • fonts-kacst & polices arabes : pour un rendu arabe parfait sans symboles manquants.
  • postgresql-client-16 : pour les sauvegardes et restaurations automatisées.

6. Lancement du Conteneur Docker & Initialisation

Lancez la compilation et le démarrage automatique des conteneurs :

cd /root/owly
docker compose build --no-cache app
docker compose up -d

# Vérifier que les 3 conteneurs sont actifs et en bonne santé
docker ps

7. Restauration de la Sauvegarde de Base de Données

Si vous avez téléchargé le fichier de sauvegarde (.sql ou .sql.gz) depuis le Dashboard précédent :

# 1. Copier le fichier de backup dans le dossier backups
cp /chemin/vers/votre_backup.sql /root/owly/backups/latest_backup.sql

# 2. Restaurer directement dans la base de données PostgreSQL Docker :
docker exec -i $(docker ps -q --filter "name=owly-db") psql -U postgres -d owly < /root/owly/backups/latest_backup.sql

# OU utiliser le script de restauration intégré dans le Dashboard :
# Rendez-vous sur https://dash.../backups et cliquez sur "Restaurer"

8. Configuration Cloudflare Worker (Taalim.org / askfne)

Sur votre compte Cloudflare (pour le domaine Taalim.org), assurez-vous que la variable AI_ORIGIN pointe bien sur l'IP/domaine de votre nouveau serveur :

const AI_ORIGIN = "http://158.69.24.123:3000"; // ou domaine direct Caddy https://...
